# `virgil.arcs`

Short arcs of an orbit: each night's velocity from its two halves, the
periods (cycle counts) that the nights' positions and velocities admit, and
each alias band's seed orbits.

::: virgil.arcs
    options:
      members:
        - night_motion
        - unwrap_cycles
        - arc_profile
        - NightMotion
        - CycleCounts
