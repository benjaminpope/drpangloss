# `virgil.tempering`

Tempering an evidence for correlated spectral channels: the effective number
of independent channels from the correlation of neighbouring channels in the
residuals, and the factor ``f = N / N_eff`` by which the log likelihood of
`fit_orbit_aliases` is divided.
